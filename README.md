# JPL Horizons Planetary Approach Leaderboard

### Python | Astrophysics | Orbital Mechanics | NASA JPL Horizons

## Project Overview

The **JPL Horizons Planetary Approach Leaderboard** is an independent Python project designed to analyze planetary motion, calculate relative distances between celestial bodies, and identify predicted closest-approach events using astronomical data from NASA's Jet Propulsion Laboratory (JPL).

The program retrieves orbital data through JPL Horizons and applies numerical analysis to investigate how distances between celestial bodies change over time.

This project was developed as part of my independent studies in physics and astrophysics, combining programming, calculus, and orbital mechanics.

## Key Features

- **JPL Horizons Integration:** Retrieves astronomical ephemeris data for planets and other supported celestial objects.
- **Customizable Reference Body:** Allows analysis relative to a selected central body, such as Earth.
- **Closest-Approach Detection:** Analyzes changes in distance to identify potential closest-approach events.
- **Numerical Derivatives:** Uses changes in distance over time to help locate distance minima.
- **Future Predictions:** Supports analysis over user-selected time windows, such as 365 or 700 days.
- **Planetary Leaderboards:** Compares celestial objects and organizes closest-approach results.
- **Distance Conversions:** Displays distances in kilometers, miles, and other useful units.
- **Data Visualization:** Plots distance variations over time to illustrate orbital behavior.
